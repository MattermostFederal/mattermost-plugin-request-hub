AI agents

Ask an agent from the Mattermost Agents plugin to file any type of request for you.

When a System Admin turns on Offer tools to Agents, an agent can file requests for you. Ask it in plain words, for example "request a private channel called Marketing Team under team- and add @alice" or "ask for a webhook in ~alerts called Build alerts". The agent acts as you, so the request follows the same rules as the form for its type: for example, you must be a member of the team or channel where the form asks for that, a channel prefix must be one your admin configured, and the request type must be turned on. As with the webapp forms, the request goes to the approvers, even when you are a System Admin.

ToolWhat it does
list_prefixesLists the channel prefixes you can use, like /mattermost-request-hub prefixes.
request_channelRequests a new channel, like the form or /mattermost-request-hub channel <prefix> <Channel name> ....
request_channel_adminAsks for channel members to be made Channel Admins, like the form or /mattermost-request-hub channel-admin @user ....
request_teamRequests a new team, like the form or /mattermost-request-hub team <Team name> ....
request_team_adminAsks for team members to be made Team Admins, like the form or /mattermost-request-hub team-admin @user ....
request_team_memberAsks for people to be added to a team, like the form or /mattermost-request-hub team-member @user ....
request_team_guestAsks for a guest invite to channels of a team, like the form or /mattermost-request-hub team-guest <email> ....
request_botRequests a bot account, like /mattermost-request-hub bot <username> <Display name> .... Like the slash command, it covers the account only; ask for an access token or webhooks for the bot in the form.
request_webhookRequests an incoming or outgoing webhook for a channel, like the forms or /mattermost-request-hub webhook-incoming ....

A request an agent filed for someone arrives in the approval channel like any other and names that person as the requester.

Agents can't approve

No agent can approve or deny a request. Those buttons stay with the people in the approval channel.

For System Admins

Turn on Offer tools to Agents in System Console → Plugins → Mattermost Request Hub. It is off by default and takes effect on save. It needs the Mattermost Agents plugin and Mattermost 11.3 or later. Once it's on, the tools above appear in the Agents plugin's own settings, where you choose which of them agents may use. Each tool follows its request type's toggle, so a type that is turned off can't be requested through an agent either.
