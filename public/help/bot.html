Docs / Bots

Request a bot

Optional access token + incoming/outgoing webhooks on the same ticket. Two-step approval (security + system) — see Approving.

How to open

  • Native: Main Menu → Integrations → Bot Accounts (non–System Admins)
  • Dropdown: channel More actions → Request a Bot
  • Hub: right App Bar plug → Requests → Request a Bot
  • Slash: /mattermost-request-hub bot opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

Form & approve

Tokens in the approval DM auto-delete after 72 hours — save them securely.

Add the bot to a team

Creating a bot does not put it on a team. After the bot exists, use Request Team Members — search for the bot username and submit the same way you would add a person. System Admins approve that ticket in mattermost-team-requests.
