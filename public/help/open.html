How to open a request

Same entry points cover most request types. Individual type pages list extras and screenshots.

Common entry points

  • Hub: right App Bar plug → Requests → pick a tile (Documentation is always listed)
  • Dropdown: channel name → More actions → the request item (when that type is enabled)
  • Slash: /mattermost-request-hub … (see Slash commands)
  • Agent: any request type through the Agents plugin, when enabled (see AI agents)

Native Mattermost spots

  • Channels: sidebar + → Request new channel
  • Channel Admin: Members panel → Request Admin
  • Teams: team sidebar menu → Request a Team / Request Team Admin
  • Team members / guests: More actions or Request Hub (guest invites default off)
  • Bots & webhooks: Main Menu → Integrations → Bot Accounts / Incoming / Outgoing Webhooks
