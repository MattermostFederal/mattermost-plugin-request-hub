Request Channel Admin

Hidden in the UI if you already admin the channel. Same form from every entry point.

How to open

  • Members: channel Members panel → Request Admin
  • Dropdown: channel name → More actions → Request Channel Admin
  • Hub: right App Bar plug → Requests → Request Channel Admin
  • Slash: /mattermost-request-hub channel-admin opens the form; /mattermost-request-hub channel-admin @user [@user ...] run in the channel skips it (see Slash commands)

Form

Pick one or more people to promote. Everyone you pick must already be a member of the channel; this request never adds anyone to it.

On approve

System Admins and the Team Admins of the channel's team can approve or deny. Team Admins of other teams, including the approval team, can't. Only a System Admin can approve a request they made themselves. Nominees who have left the channel since the request was made are skipped.
