Request Channel Admin

Hidden in the UI if you already admin the channel. Same form from every entry point.

How to open

  • Members: channel Members panel → Request Admin
  • Dropdown: channel name → More actions → Request Channel Admin
  • Hub: right App Bar plug → Requests → Request Channel Admin
  • Slash: /mattermost-request-hub channel-admin opens the form; /mattermost-request-hub channel-admin @user [@user ...] run in the channel skips it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

Form

Pick one or more people to promote. Everyone you pick must already be a member of the channel; this request never adds anyone to it.

Limits

A System Admin sets how many Channel Admin requests you can have waiting for review at once (Pending requests per user; each request type is counted separately). Asking again for the same people in the same channel while that request is pending shows you already have a pending Channel Admin request for these people in this channel. Requests that aren't reviewed within Request expiry (days) expire, and your ticket DM says so.

On approve

System Admins and the Team Admins of the channel's team can approve or deny. Team Admins of other teams, including the approval team, can't. Only a System Admin can approve a request they made themselves. Approve checks the request again first: if the requester or a nominee has left the channel or been deactivated, the approver gets a private message saying so and the request stays pending, so it can be denied (see Requests that can't be approved as they stand). An expired request can't be approved (see Expired requests).
