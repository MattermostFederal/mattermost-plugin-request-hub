Docs / Guest invites

Request guest invite

Invite an external person as a guest with channel-scoped access — not the same as adding an existing user as a full team member, and not Request Team Admin.

Guest email is required. On approve, Mattermost emails a channel-scoped guest invitation (Guest Accounts must be enabled). A regular team signup link is never returned. Tickets go to mattermost-team-requests.

Tile missing in the Request Hub? Guest invites default off. Enable Allow team guest requests in System Console → Plugins → Mattermost Request Hub, and ensure Guest Accounts are enabled. The hub tile is labeled Request Guest Invite.

Who can request

You must already be a member of the target team (System Admins may invite for any team). Open a channel on that team first — the current channel becomes the guest’s initial channel access.

How to open

  • Dropdown: channel More actions → Request Guest Invite
  • Hub: right App Bar plug → Requests → Request Guest Invite
  • Slash: /mattermost-request-hub team-guest

Form

FieldWhat it does
Guest email Required. Address that receives the guest invitation email on approve.
Message / reason Optional note for reviewers.

Click Submit request. You’ll get a DM when a System Admin responds.

On approve

  • Approve — Mattermost emails the channel-scoped guest invitation; requester notified by DM.
  • Deny — request closed; requester notified by DM.
  • Requests from System Admins are queued for approval too.
