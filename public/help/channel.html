Request a channel

Same form from every entry point. Approvers create the channel and post a welcome message.

How to open

  • + menu: channel sidebar + → Request new channel
  • Hub: right App Bar plug → Requests → Request a Channel
  • Dropdown: channel name → More actions → Request a Channel
  • Slash: /mattermost-request-hub channel opens the form; add a prefix, a name and options to skip it (see Slash commands)

Form

FieldWhat it does
Domain prefixRequired. Category for the URL (prefix + suffix).
Channel nameDisplay name (required).
URL suffixOptional; live Preview shows the final URL.
Purpose / VisibilityOptional description; Public or Private.
Members / Channel AdminsWho to add on approval (a user is in one list only).
Sidebar categoryOptional; pick existing or type a new name (created on approval).
No prefixes configured

Channel requests need at least one domain prefix. Until a System Admin defines one, the form and the slash command show: Channel requests aren't configured yet. Ask a System Admin to define at least one channel prefix in System Console → Plugins → Mattermost Request Hub.

On approve

Approval card → Approve creates the channel and posts a welcome message.
