Messaging while a request is pending

Talk to reviewers without leaving the ticket.

Every ticket links an approval Thread and a DM Thread with the bot. Replies are relayed both ways. Use Mattermost's Thread right-hand sidebar (Reply on the card) — not a new top-level message.

  • Approver: ask in the approval Thread (e.g. Why do you need this new team?)
  • Requester: see Message from @admin: in your DM Thread with the bot
  • Reply: answer in that DM Thread; the approval Thread shows Reply from @you:
Reply in the ticket thread

A brand-new DM to the bot (outside a ticket) gets a nudge to reply inside the specific request Thread instead.
