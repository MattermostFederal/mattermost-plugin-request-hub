Docs / Teams

Request a team / Team Admin

Create a new team, or request Team Admin on a team you already belong to. See also team members and guest invites.

New team: how to open

  • Native: team sidebar → Request a Team (relabeled Create a team for non-admins)
  • Team rail +: the + under teams opens Request a Team for non–System Admins
  • Dropdown: channel More actions → Request a Team
  • Hub: right App Bar plug → Requests → Request a Team
  • Slash: /mattermost-request-hub team opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

New team: form & approve

Approve first checks that the requester's account is still active; if it isn't, the approver gets a private message and the request stays pending, so it can be denied (see Requests that can't be approved as they stand).

Limits

A System Admin sets how many new team requests you can have waiting for review at once (Pending requests per user; each request type is counted separately). At the limit, you'll see you have N pending requests waiting for review; you can submit more once some are approved, denied or expire.

Asking again for a team URL you're already waiting on shows you already have a pending request for a team named name. Requests that aren't reviewed within Request expiry (days) expire, and your ticket DM says so.

Team Admin: how to open

  • Native: team sidebar → Request Team Admin
  • Dropdown: channel More actions → Request Team Admin
  • Hub: right App Bar plug → Requests → Request Team Admin
  • Slash: /mattermost-request-hub team-admin opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

Team Admin: form

Approve first checks that the team, the requester and every nominee still qualify (nominees must still be active members of the team and not bots or guests). If not, the approver gets a private message and the request stays pending, so it can be denied (see Requests that can't be approved as they stand).

Limits

A System Admin sets how many Team Admin requests you can have waiting for review at once (Pending requests per user; each request type is counted separately). At the limit, you'll see you have N pending requests waiting for review; you can submit more once some are approved, denied or expire.

Asking again for the same people in the same team while that request is pending shows you already have a pending Team Admin request for these people in this team. Requests that aren't reviewed within Request expiry (days) expire, and your ticket DM says so.
