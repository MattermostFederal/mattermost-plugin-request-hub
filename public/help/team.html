Request a team / Team Admin

Create a new team, or request Team Admin on a team you already belong to. See also team members and guest invites.

New team: how to open

  • Native: team sidebar → Request a Team (relabeled Create a team for non-admins)
  • Team rail +: the + under teams opens Request a Team for non–System Admins
  • Dropdown: channel More actions → Request a Team
  • Hub: right App Bar plug → Requests → Request a Team
  • Slash: /mattermost-request-hub team opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

Team Admin: how to open

  • Native: team sidebar → Request Team Admin
  • Dropdown: channel More actions → Request Team Admin
  • Hub: right App Bar plug → Requests → Request Team Admin
  • Slash: /mattermost-request-hub team-admin opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)
