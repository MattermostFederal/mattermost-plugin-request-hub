Docs / Team members

Request team members (add users to a team)

Ask to add existing Mattermost users or bots onto a team, not the same as Request Team Admin (role promotion) or Request a Team (create a new team).

Tickets go to mattermost-team-requests for System Admin review. On approve, nominees are added with CreateTeamMember.

Adding a bot to a team Use this same request: search for the bot’s username in Users or bots to add. The bot account must already exist (create it first with Request a Bot if needed). Approval is the same System Admin queue as for people.
Tile missing in the Request Hub? Enable Allow team member requests in System Console → Plugins → Mattermost Request Hub, then reopen the hub. The hub tile is labeled Request Team Members (description: “Ask to add existing users or bots to your current team.”).

How to open

  • Dropdown: channel More actions → Request Team Members
  • Hub: right App Bar plug → Requests → Request Team Members
  • Slash: /mattermost-request-hub team-member opens the form; add arguments to skip it (see Slash commands)
  • Agent: when Offer tools to Agents is on, ask an AI agent to file it for you (see AI agents)

Form

Targets the team you are currently viewing. Switch teams first if needed.

FieldWhat it does
Users or bots to add Pick one or more existing Mattermost users or bots not already on that team.
Reason Optional context for reviewers.

Click Submit request. You’ll get a DM when a System Admin responds.

Limits

A System Admin sets how many team member requests you can have waiting for review at once (Pending requests per user; each request type is counted separately). At the limit, you'll see you have N pending requests waiting for review; you can submit more once some are approved, denied or expire.

Asking again for the same people in the same team while that request is pending shows you already have a pending request to add these people to this team. Requests that aren't reviewed within Request expiry (days) expire, and your ticket DM says so.

On approve

  • Approve: nominees are added to the team; requester is notified by DM.
  • Deny: request closed; requester notified by DM.
  • Requests from System Admins are queued for approval too.
  • Approve first checks that the team isn't archived or managed by groups and that the requester and nominees are still active; if not, the request stays pending so it can be denied (see Requests that can't be approved as they stand).
