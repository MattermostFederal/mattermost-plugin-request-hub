Mattermost Request Hub

Ask for workspace changes that need an admin sign-off — without granting everyone create permissions.

What it is

Mattermost Request Hub turns “I need a channel / team / bot / webhook …” into a request ticket. An approver reviews it; on approve, Mattermost creates or applies the change and notifies the people involved.

While a ticket is open, you and the approver can talk in a linked Thread (approval card ↔ your DM with the bot). Replies relay both ways.

What you can request

TypeResult on approve
ChannelNew channel, members, and Channel Admins
Channel AdminNominated users become Channel Admins on an existing channel
TeamNew team, optionally with you as its Team Admin
Team AdminYou, or the team members you name, become Team Admin on the current team
Team membersExisting users added to the team
Guest inviteChannel-scoped guest invitation email (email required)
BotBot account (± token / webhooks)
WebhookStandalone incoming or outgoing webhook

Which types appear depends on System Console toggles. Open this overview anytime with /mattermost-request-hub docs.

How to open (any type)

  • Hub: right App Bar plug → Requests → pick a tile
  • Dropdown: channel More actions → the request item
  • Native: + menu, Members panel, team sidebar, or Integrations (type-specific)
  • Slash: /mattermost-request-hub … — see Slash commands
  • Agent: any request type through the Agents plugin, when enabled (see AI agents)

Details and screenshots: How to open requests.

How a request flows

  • Submit — fill the form from hub, native menu, More actions, or slash command
  • Review — approval card in a private requests channel; optional Thread Q&A
  • Decide — Approve creates/applies the change; Deny closes the ticket
